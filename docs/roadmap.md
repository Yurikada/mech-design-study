# 個別技術と統合技術を同時に学ぶロードマップ

目的は完成品の機能数を増やすことだけではない。「理解→仮定→計算→検証→統合→設計判断」の一周を、小さなケースごとに繰り返す。

M0の基準モデル、M1の比較CLI、M2aの梁FEMを実装済み。各段階の本人の学習確認は実装の動作確認と分ける。以下はロードマップであり、全分野の実装・学習完了を意味しない。学習時間の見積もりは未設定。

| 段階 | 個別技術の学習 | 統合技術の学習 | 完了の証拠 |
|---|---|---|---|
| M0 基準モデル | 梁応力・たわみ・固有振動数・1D熱伝導 | SI入力、評価器分離、制約・未評価管理 | 手計算・数値テスト＋本人の説明 |
| M1 複数案比較 | 寸法依存、感度、支配制約 | ケース比較、条件同一性、結果の来歴 | 板厚・幅・長さを変えた比較と理由 |
| M2 数値解析 | 応力・熱・振動FEM、メッシュ配置・要素形状・次数・品質、境界条件 | ソルバーアダプター、メッシュと設定の来歴、失敗処理 | 解析解とFEMの差、h収束、形状・次数を変えた比較 |
| M3 製法と作業 | 製作可能性、組立順序、工具空間、交換作業 | 幾何制約、離散判定、人の確認 | 製法を一つ決めた部品と着脱試験 |
| M4 形状探索 | トポロジー最適化、密度法、フィルタ、製造制約 | 目的と制約、探索、形状の再評価 | 標準問題再現と最終形状の再解析 |
| M5 時間と寿命 | 疲労、環境劣化、クリープ・応力緩和 | 使用履歴、材料データ、適用範囲、不確かさ | 一つの機序についてデータ付き比較 |
| M6 電気との接続 | 回路損失、EMCの励振・配線・接地 | ECAD連携、物理連成、計算コスト管理 | 既定回路から熱入力、EMベンチマーク |
| M7 実験との接続 | FRF、実験モード、支持剛性・減衰の同定 | 校正と検証の分離、モデル更新 | 校正以外の条件での予測照合 |

## ケースを広げる際の判断

M2は[講義3](learning/03-fem.md)の二段階で進める。実装済みのM2aは三次Hermite梁要素で静解析・自由振動とh収束を確認する。現在の先端力ケースの静的変位は1要素でも厳密に表せるため、メッシュ収束の主指標には固有振動数を用いる。M2bの純曲げ比較は実装済みで、平面応力の三角形・四角形、一次・二次を比較し、自由度数・ゆがみ・積分法・応力評価位置も記録する。熱FEMはその後の拡張として残す。

全分野を同じ精度で同時に実装しない。対象部品で意味を持つ機序を選ぶ。各段階で、入力の出典、数値実装の検証、実機妥当性、本人が説明できるかを別々に記録する。

確認テストは節目でまとめ、次へ進むのに十分な理解が確認できたら次の講義・実装へ移る。資料の一問一答は復習用にも使い、全問の対話回答を進行条件にしない。

M2bの比較条件と実装結果は[講義4](learning/04-fem-benchmark.md)に記載する。純曲げの平面応力参照解と整合する条件を定め、要素・分割・積分法・ゆがみを段階的に比較する。純曲げの20条件を計算済み。別モデルのCodexレビューと指摘修正を実施済み。本人の実行・解釈確認と、曲率が変わるケースは残る。以降の講義にも一問一答・解答例・解説を併記する。

将来の統合ケース候補は「発熱する基板の筐体・支持ブラケット・交換可能な蓋」。製法、材料、使用環境、試験手段はまだ未決定。M0の梁をそのまま筐体モデルと見なさない。
