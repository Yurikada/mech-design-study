# ADR 0001: 解析解を用いた最小の統合環境から開始する

- 日付: 2026-09-07
- 状態: 初期構成として実施。将来変更可能。
- 本人の目的: 個別の設計技術と統合する仕組みの両方を学ぶ。
- 本人の公開範囲指定: GitHub非公開で開始。

## 判断

Python 3.12以上、専用venv、標準ライブラリの計算コア、TOML入力、CLI/JSON出力とする。pytestとRuffを開発依存に持ち、WindowsとLinuxのCIで再現を確認する。

第一ケースは一様片持ち梁の構造・振動と1D熱伝導。共通の寸法で複数の指標が変わるため、個別の式を追いながら統合を学べる。初期実装はAI支援で用意した足場であり、本人の独力実装・理解完了とは表現しない。

## 効果と制限

- ソルバーのライセンス・CAD環境なしで実行できる。
- 手計算と実装結果を照合できる。
- 回路・EMC・疲労等は未評価と明示する。
- 本格的な筐体や熱構造連成を表現できない。
- UI、最適化エンジン、FEM、データベースの選択は、それぞれの学習課題が具体化してから行う。

OpenMDAO等の採用判断は評価器間の依存、反復、微分、探索規模を確認するM2以降で行う。初期の数個の式にフレームワークを先に要求しない。

ライセンスの公開付与、GitHub Pages、クラウド計算、外部API、ソルバー導入は今回のセットアップに含まない。
