# 第一ケース: 加熱される片持ち支持板

講義から進める場合は [図付き講義](01-lecture.md) または [ブラウザ版](01-lecture.html) を読む。講義は以下の4つの完了条件に対応し、Q1〜Q4で確認する。

目的は、式・前提・数値・合否を追える最小例で、個別物理と統合の両方を学ぶこと。AIが式と初期コードを用意しているため、実行成功だけでは学習完了としない。

## モデルを図にする

長さ方向をx、幅をb、曲げ方向の厚みをtとする。x=0は完全固定、x=Lには厚み方向の静的横荷重Fを加える。梁は一様断面・線形弾性・小変形。振動は同じ梁の自由振動で、先端付加質量なし。重力、せん断変形、回転慣性、締結部の柔らかさは含まない。

熱はx=0を一定温度に保ち、x=Lから熱量Q [W]を入れる。側面は断熱。Qは質量を持つヒーターの動的影響を表さない理想境界条件。

## 式と確認点

断面積と断面二次モーメント:

```math
A=bt, \qquad I=\frac{bt^3}{12}
```

固定端の公称曲げ応力と先端たわみ:

```math
\sigma=\frac{FL(t/2)}{I}, \qquad \delta=\frac{FL^3}{3EI}
```

一次の固有振動数:

```math
f_1=\frac{1.875104^2}{2\pi L^2}\sqrt{\frac{EI}{\rho A}}
```

先端温度と質量:

```math
T_{tip}=T_{base}+Q\frac{L}{kA}, \qquad m=\rho AL
```

モデル実装は `src/mech_design/models.py`。導出の入口は [MIT構造力学](../references.md) と [FunctionBayの片持ち梁解説・式(5.41)](https://help.functionbay.com/2026/RecurDynHelp/Analysis/Analysis_ch04_s05_03.html)。梁振動の式はEuler–Bernoulli方程式の固定・自由境界条件から得る。熱の式は定常・一次元・熱伝導率一定のFourier則を積分する。

## 実験前の予想

次の問いについて自分の予想を書いてから計算する。回答欄は本人が記入する。

- tを2倍にすると、質量・応力・たわみ・周波数・温度上昇はそれぞれ何倍になるか。
- 幅を変えると応力や温度が変わるのに、この理想梁の曲げ固有振動数には現れないのはなぜか。
- Fを3倍にしても、このモデルの固有振動数が変わらない理由は何か。
- 現実に先端へおもりを付けた場合、この振動式をそのまま使えるか。
- 応力が閾値以下なのにたわみが違反することはあるか。
- 熱計算を実行しただけで、熱応力や温度依存弾性率まで評価したといえるか。
- 長さ／厚み比10と、たわみ／長さ比0.05の入力ガードだけで、梁理論の妥当性が保証されるか。

## 実施手順

1. 基準ケースを実行する。手計算でI、応力、たわみ、熱収支を確認する。
2. ケースをコピーし、板厚だけを2 mmに変える。
3. どの制約が違反するかを記録し、応力だけを見る場合との判断の違いを説明する。
4. 長さだけ、幅だけ、荷重だけを変えたケースを作り、予想を確認する。
5. 次の実装課題として「複数ケースの結果を並べて比較する機能」の入力・出力を設計する。

## 完了条件

- 4つの指標の式を、入力・単位・境界条件から説明できる。
- 数値が合うことと、実機に適用できることの違いを説明できる。
- 3 mmと2 mmの比較結果を再現できる。
- 新しい評価器を追加する場所と、未評価が合格にならない仕組みを説明できる。
